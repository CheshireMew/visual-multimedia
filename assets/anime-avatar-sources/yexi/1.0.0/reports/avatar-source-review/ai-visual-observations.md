## 明确不能推出的结论

- 不能把浅微笑、小横口或自然小嘴自动命名为 CLOSED。
- 不能仅凭这些候选画面建立 A、I、U、E、O 分类；需要结合真实发音和更严格的视觉语义复核。
- 不能证明同一强度的动作有足够多独立 take，也不能证明任意有向状态转换自然成立。
- 不能证明把这些区间前后跳转、循环或光流拼接后仍然自然。
- 不能证明这段素材可以对齐任意普通话台词。
- 不能用“存在大开口”“完整解码”或“可生成 MP4”替代口型匹配和自然度验收。
