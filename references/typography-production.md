# 网页视觉的字体选择与真实命中

用于技术图解、字幕包装、网页动画和其它受支持网页视觉在制作前选择字体，在项目中保存标题、正文与元信息的字体角色，并在真实浏览器中证明最终使用的字体和字重。它不替当前内容选择视觉风格，也不把一种字体变成所有项目的默认审美。

## 一、选择顺序

先读取当前项目或系列已经确认的 `style-profile.json`。没有已确认字体时，依次使用用户或品牌明确提供的字体、当前项目显式采用的注册 `production-assets` 字体、当前 Windows 环境已经验证可用的内置预设。参考图只影响用户明确要求参考的字体气质；没有实际字体来源时，根据当前内容选择相近且真实可用的预设。

当前 starter 的预设目录承担八类常见职责，其中后五款是本轮登记的明确候选：

- 现代中文信息：Noto Sans SC 标题与正文，适合技术说明、清单、图解和界面信息；标题通常使用 700–800，正文使用 500–600。
- 编辑阅读：Noto Serif SC 标题配 Noto Sans SC 正文，适合评论、引用、文化与出版感内容；标题通常使用 650–750，正文使用 500–600。
- Windows 通用中文：Microsoft YaHei 标题与正文，用于当前机器缺少 Noto 字体或项目明确选择系统无衬线时；标题通常使用 700，正文使用 500–600。
- 方正舒体：只用于舒展、书写感明显的短标题，正文配 Noto Sans SC；不用于长正文、数据与制度文本。
- 方正姚体：只用于端正而有装饰性的文化、节庆或醒目标语标题，正文配 Noto Sans SC；不用于小字号与长正文。
- Noto Sans SC Black：以 900 字重承担强标题，正文仍使用中等字重 Noto Sans SC；适合现代、高对比的信息层级。
- 方正祥隶：只在当前机器存在完整字库时用于传统、民俗和参考图明确需要隶意的短标题。少数字形子集不能登记成完整字体，也不能支撑一般文案。
- 字魂4181温暖童稚影体：按用户指定的精确名称登记，只在精确字体文件存在且授权明确时用于儿童、亲子和轻松标题；名称相近的字体不能静默替代。

数字需要纵向比较时继续在当前字体中启用等宽数字；命令、路径和代码片段可以使用项目已经确认的等宽字体，并为中文提供同一正文回退。书写感字体只在当前项目明确采用来源、权利和实际文件都成立的字体资源时进入项目，不从题材或案例自动推断。

## 二、保存字体角色

项目 `style-profile.json.shared_visual_core.typography` 至少记录标题、正文和适用时的元信息角色：实际字体家族、字重、来源和使用位置。网页清单使用独立主题变量保存标题字体、正文字体、标题字重和正文字重；页面 CSS 只读取这些变量。字号、行高、字距与具体构图继续由当前作品决定。

同一角色只保留一个活动值。项目从系统字体迁移到随包字体时，同时更新字体资源、`@font-face`、主题默认值、风格档案和全部使用位置，旧字体声明退出；不保留一套设计说明和另一套实际 CSS。

## 三、字体来源与网页包

系统字体只在当前机器已经验证存在时作为本机制作来源。预设目录保存字体角色、精确本机名称、适用范围、禁用范围和来源说明，不内置商业字体文件。方正字体只检测本机安装状态；商用、发布或嵌入前按实际授权范围核对。需要跨机器继续编辑或承诺网页包独立携带字体时，从已注册的 `production-assets` 采用授权字体，把实际字体文件与许可证放入包内资源，再由相对路径 `@font-face` 加载。Microsoft YaHei 等系统字体只作为系统回退，不能复制进可分发包冒充项目素材。

字体来源、权利或文件不清楚时，选择当前环境已经验证的预设并如实记录，不下载来源不明的字体。采用字体资源后，网页清单 `resources`、实际文件、CSS 声明和素材采用记录共同指向同一份资源。

## 四、浏览器验收

浏览器先对预设中的每个精确本机名称执行 `new FontFace(..., local(...)).load()`。标题与正文角色都命中后才能启用该预设；`document.fonts.check()` 会把 CSS 回退也算作成功，不能用来证明指定字体存在。应用字体后再等待 `document.fonts.ready`，读取标题与正文代表节点的计算样式，并确认实际字重与项目记录一致、中文英文数字和符号没有局部回退造成明显颜色或宽度变化、标题分行和缩略图阅读仍成立。

字体加载完成只说明浏览器结束了字体处理。只有精确本机名称探测成功、代表节点计算样式与主题变量一致，并且目标尺寸实际画面可读，才能说当前字体已命中。未安装预设在编辑器中保留为禁用项并说明原因，不能应用、不能回退成另一款字体，也不能在说明中声称已经使用。
