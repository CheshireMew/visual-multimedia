# 参考视频复刻、对齐与证据

只在用户明确要求按一段参考视频复刻、匹配、逐帧对齐或比较候选成片时使用。普通风格参考、剪辑灵感、同类案例和常规导出不进入这条高强度路线。

## 一、先确定当前要证明什么

把参考文件、参考区间、候选文件、候选区间和目标层级说清楚。没有指定区间时以完整视频为对象；只提供网页、分镜或截图而没有候选成片时，可以先完成参数化制作，但不能声称已经通过逐帧交付验收。

还原层级按当前用户结果选择：

1. **源文件一致**：交付物就是被授权复制的同一媒体流，文件摘要或明确允许的封装差异能够证明来源身份。
2. **渲染帧一致**：无损渲染帧在相同帧位置逐像素一致，编码交付物另行说明编码造成的差异。
3. **编码后帧对齐**：最终候选的每个解码帧都与正确参考帧保持时间身份，差异处于当前任务明确接受的编码范围。
4. **视觉对齐**：构图、对象状态、文字、色彩和动作节奏符合当前约定；允许已说明的渲染或编码差异。
5. **风格参考**：只继承用户点名的视觉、运动或剪辑语言，不声称布局、帧序或像素还原。

层级越高不代表结果一定更好。用户只要风格借鉴时停在风格参考；用户要求逐帧或像素对齐时不能用“看起来接近”代替帧证据。数值阈值来自用户、项目或当前交付规格，不把任何单个案例的误差、时长和帧数升级成全局默认。

## 二、精确回放与参数化重建分开

- **精确回放**保存指定参考区间的真实帧身份，目标是证明当前参考本身被正确读取、定位和交付。
- **参数化重建**用可修改对象、样式和确定性运动重新实现可复用结构，目标是让未来内容能够改变文字、数据、素材和时长。

两者可以在同一任务中都交付，但必须作为两个结果分别命名、制作和验收。精确回放通过不能证明参数化重建正确；参数化重建可编辑也不能证明它逐帧等于参考。参考素材的使用权只约束精确回放和直接复制的资产，不因为重建成功自动获得分发权。

## 三、资产证据

开始实现前确认：

- 参考文件能够真实读取，文件摘要、视频流、尺寸、帧率、帧数和时长已经记录。
- 参考与候选区间使用明确的起始帧和比较帧数；不能把近似秒数、播放器截图或手写帧号当成区间真源。
- 需要从参考抽取图片、序列或精确回放素材时，抽取数量与目标区间一致，首尾帧能够回到真实参考。
- 参数化重建使用的字体、图片、图标、声音和视频素材分别经过现有素材账本与权利检查；参考视频本身不替代这些素材事实。

参考帧、联系表和误差图是当前任务的诊断证据，不自动注册成共享组件或素材。只有重建结果确实可复用、权利收口并经过现有晋升流程时，才进入注册资源。

## 四、运行时证据

参数化网页继续只使用 `editable-media` v5 和 `window.__hf.duration/seek(seconds)`。在开始、全部必要变化、场景边界和结束状态随机定位，确认同一时间得到同一帧；不得为参考复刻增加 `window.__timelines`、第二套计时器或只服务某个案例的回退运行时。

精确回放与参数化重建都要实际推进完整目标区间。只验证第一个场景、顺序播放、单张截图或脚本对象存在，不能证明任意定位和边界状态正确。参数化重建还要按 `content-to-media.md` 已确定的运动载体、状态变化和文字职责完整播放，避免逐帧指标掩盖“结构上仍是幻灯片”的问题。

## 五、交付证据

只有最终候选文件生成后才执行逐帧比较。比较至少记录：

- 两个真实文件的 SHA-256、视频流、尺寸、帧率、帧数和实际比较区间。
- 对齐位置的逐帧摘要、完全一致帧比例、平均与最大绝对误差、最低 PSNR、最差帧和首尾边界误差。
- 在用户要求检查时间错位时，为每个候选帧搜索附近参考帧，报告最佳偏移和非零偏移数量；时间错位不能被较低的邻帧误差掩盖。
- 由最终候选解码出的最差帧、边界帧和联系表；不能用网页截图、缓存帧或制作过程中的临时序列冒充交付物。

MediaFlow Pro 公开合同实际声明 `quality.reference.compare` 时，用它读取参考与候选文件并生成 `reference-comparison.json`、最差帧对照图和联系表。请求由本次 `mediaflow-cli describe` 的参数 schema 组装；典型参数包括两个文件路径、各自起始帧、比较帧数、邻帧搜索半径、边界帧数量、输出目录、可选验收阈值和显式覆盖开关。未声明该操作时保留当前成片和已完成的人工检查，说明缺少机器比较能力，不用外部示例项目的脚本或私有编辑器实现替代。

机器比较只证明文件、帧和数值关系。视觉对齐与风格参考仍要打开最终成片，从头到尾检查构图、文字、对象状态、动作节奏、转场和声音。最终只声明当前机器证据与人工观看共同支持的最低层级；任一道证据不足时降低声明或继续修复，不把预期层级写成已经完成。

## 六、交付说明

向用户交付：

1. 参考与候选的真实文件和区间。
2. 本次目标层级，以及精确回放或参数化重建的身份。
3. 可编辑真源和最终候选成片。
4. 逐帧比较报告、最差帧与联系表，以及实际完整观看结论。
5. 仍存在的差异、允许差异的依据和当前能够诚实声明的还原层级。

只要用户要求的层级已经由对应证据证明且结果可实际使用就停止，不为形式完整继续追求更高层级。
