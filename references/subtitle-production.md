# 生产字幕

用于主入口当前视频默认基线要求字幕，或用户要求从最终旁白、最终合并视频、已经复核的转写生成可交付字幕时。它负责把真实时间边界组织成可读短语，生成唯一字幕时间线及 SRT、VTT 和质检报告；事实转写、媒体素材与最终声音仍由上层同时选择的项目合同负责。

## 一、先确定时间与文字真源

最终音频或最终合并视频决定时间。先取得已经通过听音复核的 `transcript.json`，确认它绑定当前 source id、原片哈希和真实字幕或 ASR 输入；原片或确认文案变化后重新转写或对齐，不能沿用旧字幕时间。

上屏文字从已经确认的媒体文案或人工校正文本派生。ASR 只提供定位，不把误识别文字变成显示真源。需要改变措辞时先更新活动媒体文案，再重新生成字幕；只调整断句时保持事实、数字、专名和关键条件不变。

当前视频默认基线生效时，从同一组 cue id 和真实声音边界建立中英文两层文字：与声音一致的原语言保存确认原文并作为主层，另一语言是逐条核对事实、数字、专名和语气后的自然译文，并作为次层。译文不能重新运行 ASR、另估时间或建立第二套 cue；两个字幕轨共同消费同一字幕时间线。用户明确改为单语、其它语言或无字幕时，以本次要求替换基线，不保留已经退出的字幕轨。

## 二、先断短语，再生成机器产物

Agent 根据听感、语义和目标画布编写一个带真实时间码的 SRT 输入。每条 cue 保留一个能够独立读懂的短语：连接词与它引出的内容放在一起，ASCII 产品名、型号和缩写保持完整，停顿只在确实形成阅读边界时断开。合成输入里的谐音、停顿标记和读法替换不得进入字幕。刻意使用的单词强调可以保留，但要在本次验收参数或审阅说明中明确，不把普通句子切成孤立碎片。

然后运行：

```powershell
node scripts/production-captions.mjs build `
  --transcript <项目目录>/transcript.json `
  --input-srt <项目目录>/captions.source.srt `
  --output-dir <项目目录>/captions
```

生产者生成：

- `captions.json`：唯一字幕时间线，绑定转写与原片哈希；
- `captions.srt`、`captions.vtt`：从同一时间线导出的便携字幕；
- `caption-qc.json`：时间覆盖、时长、阅读负担、碎片、连接词和受保护 ASCII token 检查。

默认阈值是可覆盖的算法参数，不是协议不变量。语言、画布、字号、受众或刻意节奏改变时，通过命令行显式调整；不得为了让报告通过而改变最终声音时间或隐藏字幕内容。

## 三、共同消费一条时间线

字幕烧录、外挂字幕、关键词显现、场景切换和其它需要文字时间的消费者读取 `captions.json` 或由它导出的 SRT/VTT。下游不再根据文案长度估算时间，也不维护第二套 cue。需要 ASS 时，从已经通过的时间线派生样式化 ASS，并按目标画布核对字号、换行和安全区。

用户确认过的字号、字体、位置、描边、语言层级和每种语言的最大行数组成当前字幕样式；后续只改文字或时间时必须继承，不因重建 ASS 或更换预览规格漂移。双语字幕分别遵守各自的行数和安全宽度，译文使用较弱层级，但不把两个语言挤进无法阅读的小字号。样式变化只影响字幕与下游预览，不回写口播或剪辑选择。

字幕样式要求水平居中时，基准是完整输出画布的水平中线，除非用户明确指定另一个锚点。ASS 或其它排版不能通过扩大单侧边距，把“剩余安全区域的中心”冒充画面中心；使用对称边距或绑定完整画布的明确位置，并比较实际字幕包围盒中心。需要避让右下角人物窗、平台控件或局部证据时，优先调整字幕的纵向带、断句换行或可编辑底片布局；确需偏移时把它作为用户可见的构图决定，不让所有字幕无声地整体偏向一侧。

`caption-qc.json` 为 `failed` 时，回到 SRT 断句或真实转写边界修订后重新生成。报告为 `passed` 后仍要观看目标尺寸成片，并听取每个删句、拼接和停顿边界，确认没有夹带前后句的残字、半个音节或被截断的尾音；机器报告不替代最终画面审阅。

## 四、通过标准

- 时间线绑定当前复核转写和当前原片哈希，所有 cue 位于真实声音范围内且不重叠。
- 字幕短语能够独立阅读，没有孤立连接词、明显碎片或被拆开的受保护产品名与型号。
- 阅读负担和最短时长符合当前项目显式采用的参数；警告已经由 Agent 结合真实成片处理。
- SRT、VTT、JSON 与质检报告来自同一次生产，字幕消费者读取同一时间线。
- 已确认字幕样式被继续继承，双语层级、字号、行数与安全宽度在目标尺寸可读。
- 当前视频默认基线生效时，中英文两层引用同一 cue 和真实声音边界；原文与译文的事实、数字、专名和语气一致，最终画面确实同时显示两层。
- 声明居中的字幕在短句、长句和双语代表 cue 中都以完整画布为基准，没有因单侧避让产生持续偏移。
- 最终成片或播放器中的字幕已经实际观看并听过编辑边界，文字、声音、换行、时间和画面关系成立。
