# 语义图形动效制作

用于把能够拆成稳定视觉部件的图形对象制作成可编辑、可定位、可导出的动画。Logo 是适用输入之一，但不是特殊协议；图标、字标、线稿、简单插画部件、示意图节点、符号和 UI 微图形使用同一方法。照片、实拍、整页界面截图、依赖像素纹理的复杂插画和没有可靠部件关系的位图不走这条路径。

本流程只扩展现有网页视觉制作方法。交付仍是 editable-media v6 网页包，结构化编辑入口仍是 `window.editableMedia`，逐帧时间入口仍是 `window.__hf.duration/seek(seconds)`。不新增 Logo 专用清单、第二套时钟、私有渲染参数或消费端恢复逻辑。

## 一、先确定对象职责和静态合同

开始前记录对象在成品中的真实职责、出现位置、观看尺寸、背景关系、输出载体和获准静态状态。静态状态可以来自用户确认的原图、现有矢量资产或已经通过构图审阅的网页帧。它约束形状、负形、字形关系、颜色、层级和最终停留状态，不预先规定动画类型。

判断输入能否可靠拆分：观众能否指出它由哪些形状、笔画、容器、符号或文字部分组成；这些部分是否具有稳定前后关系；拆分后能否在目标尺寸保持识别。答案不成立时停止矢量重建，保留原素材并在现有网页或视频链路中做整体运动、遮罩、镜头或状态变化。

文字只有在字形本身就是运动对象时才参与轮廓动画。仍需编辑、翻译或准确阅读的文字继续由网页内容字段和已验证字体渲染，不把它永久转成不可编辑路径。

## 二、用最低必要复杂度重建图形

已有合格 SVG 时先整理分组、坐标和稳定 ID，不重新描一遍。只有栅格图或现有矢量无法承担对象级动画时才重建：先使用圆、圆角矩形、直线、弧线和少量控制点的路径；复杂轮廓跟踪只作为测量起点，不能把像素锯齿当成最终几何。

重建按以下顺序判断：

1. 对齐外轮廓、关键转折、端点、中心线和主要负形。
2. 在实际观看尺寸检查识别、曲率连续、左右重量和局部厚度。
3. 用半透明叠图、前景交并比和像素差定位偏离区域。
4. 指标只帮助找问题。更高的像素重合不能推翻结构、平滑度、字形关系或负形已经变差的事实。

同一视觉部件只保留一个几何真源。装饰高光、阴影或描边能够从主形状派生时由 CSS 或 SVG 属性产生，不复制一份近似轮廓。为了动画需要把连续对象分段时，分段位置放在真实遮挡、笔画连接、层级交接或不易察觉的曲率区，并在最终静态状态恢复无缝关系。

## 三、建立可动语义部件

按观众能够理解的角色命名和分组，例如主体轮廓、内核、轨道、节点、连接笔画、强调点和字形组，不按导出软件自动产生的路径序号组织。每个需要编辑、定位或单独运动的部件使用稳定 `data-editable-id`，并进入当前网页包已有的图层、数据、主题或参数边界；不在动画脚本中再维护一份形状清单。

先决定部件的最终层级和静态变换，再建立动画内层。需要同时接受编辑器位置、旋转或透明度覆盖时，使用“可编辑外层 + 动画内层”，避免运行时和动画争夺同一个属性。路径长度、变换原点和遮罩尺寸都从当前真实几何取得，不复制魔法数字冒充资产合同。

部件只有在独立运动能够表达生成、连接、组合、切换、反馈、循环或注意力转移时才拆开。为了增加动作数量而把完整图形切碎，会破坏识别和编辑，应当合回去。

## 四、从含义选择运动结构

先读取当前风格档案的 `time_motion`，再根据对象职责选择一种主结构：

- **揭示**：对象从不可见或未完成进入完整状态，适合路径绘制、遮罩展开、部件组装和身份出现。
- **状态转变**：同一对象的值、形状、方向、层级或关系发生一次可读变化，完成后保留结果。
- **循环**：对象表达持续运行、呼吸、扫描、传递或周期关系，首尾语义与画面都必须连续。
- **交互**：用户操作直接改变对象状态；录制和导出仍把同一状态变化映射到统一绝对时间。

动画强弱、节奏、缓动、错峰和夸张程度来自对象性格、使用场景、观看距离和当前内容，不套固定黄金比例、统一分段百分比或动画原则清单。Logo 不默认使用 reveal；图标也不默认循环。一个对象有多个阶段时，先写“开始状态 → 发生的变化 → 可观察结果 → 是否保持或回到起点”，再为这些语义边界安排时间。

路径绘制、多部件接续和形状变换要特别检查交接。前一部件尚未建立方向时，后一部件不能凭空弹出；前一动作已经停止而后一动作延迟过久时，应调整重叠、速度或语义停顿，而不是用更多装饰掩盖断裂。自相交路径优先拆成具有明确遮挡关系的部件，不能只依赖一条 dash 动画期待浏览器自动产生正确前后层级。

面向用户的网页成品遵守 `prefers-reduced-motion`：保留完整静态结果和必要状态反馈，取消大幅位移、持续循环和非必要绘制过程。用于确定性导出的捕获模式仍由明确时间定位，不能让系统动效偏好改变同一项目的渲染结果。

## 五、在现有网页合同中实现

清单中的场景、步骤、图层、参数和质量规则继续表达对象的开始、变化、结果与保持状态。SVG 结构和动画算法保存在当前网页入口，内容和主题值从清单进入；不要把整段 SVG 字符串同时塞进清单和 HTML。需要外部 SVG、图片或字体时按现有素材账本和包边界导入。

所有时间函数都应是绝对时间的纯计算：任意定位到同一毫秒都得到相同的路径进度、部件变换、遮罩、颜色和层级。不要用累计 `requestAnimationFrame`、CSS 动画自然运行时间、随机起点或互不知情的计时器决定捕获画面。普通预览可以播放，但播放只是连续调用同一时间计算。

获准静态状态通常是非循环动画的结果帧。循环作品则另外保存一个代表性完整状态，并证明首尾边界连续。最终导出继续使用当前选择的 MediaFlow Pro、本地渲染器或 HyperFrames 提供者，一次只走一条已经声明的路径。

## 六、检查拟合和运动连续性

先用 `scripts/validate-editable-media.mjs` 从真实网页定位开始、变化、结果和保持步骤。对于栅格重建、路径接续、形状变换、多部件汇合或曾出现卡顿跳变的对象，再从同一个 `window.__hf` 时间边界密集捕获风险窗口的有序帧，并运行：

```powershell
python scripts/audit-semantic-graphic-motion.py --frames-dir <帧目录> --approved-state <获准静态图.png> --report <报告.json> --overlay <拟合叠图.png> --contact-sheet <连续性联系表.png>
```

脚本比较最终真实帧与静态合同，计算像素差和前景交并比，并检查逐帧变化中“连续静止后突然跳变”的信号。它只负责定位风险，不自动宣布视觉结构正确。叠图、联系表和报告必须与实际播放一起查看；结构、识别、负形、曲线平滑、运动含义和最终观看尺寸仍由人工审阅。

风险窗口围绕真实交接点采样，不能只取均匀分布的少量漂亮帧。至少查看交接前、交接中、交接后和结果保持；发现异常后回到同一网页几何或时间函数修改，再重新捕获，不在分析脚本或消费端修帧。

## 七、完成条件

同一方法至少能够处理一种标志类对象和一种非 Logo 图形对象；两者都由语义部件和当前内容决定运动，而不是改名复用同一表面动画。网页能够定位任意时间，编辑值与动画状态同时成立，获准静态结果没有结构退化，风险窗口没有无法解释的停顿、跳变、穿帮或层级反转，实际导出与浏览器关键状态一致。

本方法吸收了 [Pixel2Motion](https://github.com/nolangz/pixel2motion) 对平滑低复杂度矢量、可动语义部件、静态结果合同和风险窗口审阅的经验。Pixel2Motion 由 Nolan Lai 以 MIT License 发布；这里重新实现为产品无关的通用图形流程，不复制其 Logo 专用入口、时间协议、固定配方或源代码。
